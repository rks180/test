Task 2.2 — Schedule a message

    

      POST /api/messages { message, day, time } — stored now with status
      scheduled; a cron poller flips it to sent at that day/time
      (server local timezone). A past time is delivered on the next poll (≤ 1 min).
    

    

      
      
      
      
      
    

    

      
    

    

  


  

    
Task 2.1 — Real-time CPU monitor — auto restart at 70%

    

      GET /api/cpu is polled every second. Click CPU stress → CPU climbs →
      once 3 samples in a row stay above 70% the server restarts itself
      (npm start, cluster mode). The changing worker PID below is the proof.
